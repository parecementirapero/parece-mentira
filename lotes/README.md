# Lotes

Una carpeta por lote: `AAAA-MM-DD-manana` (08:00, ordenador de Nico) o `AAAA-MM-DD-tarde` (20:00, ordenador de Jorge).

Dentro de cada lote, solo texto:
- `guiones.md` — guion de locución de cada vídeo (cifras en letra) y fuentes.
- `metadatos.json` — título, descripción y hashtags por plataforma.
- `estado.md` — enlace a la subcarpeta de Drive, estado (en revisión / aprobado «ok» / publicado) y enlaces publicados.

Los MP3 y MP4 van a Drive, no al repo.
`IDEAS.md` (en esta carpeta) guarda la lista de temas y cuáles ya se han usado, para no repetir.
